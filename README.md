# Журнал ремонта кранов

Облачное приложение для работы с телефона и компьютера: ASP.NET Core 10, Identity, PostgreSQL 17. Исходный проект находится в [cloud-journal](cloud-journal/README.md).

## Состояние подготовки

Исходники подготовлены. Загрузка в репозиторий, GitHub Actions и развёртывание Render пока не завершены. Локально выполнены 8 JavaScript-проверок. Сборка C#, интеграционные проверки PostgreSQL/HTTP и Docker-сборка должны успешно пройти до рабочего запуска.

## Проверки на GitHub

Файл `.github/workflows/cloud-journal.yml` запускает три задания: клиентские проверки, сборку и серверные проверки с отдельной временной PostgreSQL, затем сборку Docker-образа. Права workflow ограничены чтением кода. Пароль `ci-checks-only` относится только к одноразовой тестовой БД; рабочие секреты и MAX не используются. Workflow ничего не публикует и не выполняет развёртывание.

После загрузки откройте вкладку **Actions → Cloud journal checks** и убедитесь, что все три задания завершились успешно. Подробности проверок: [VERIFICATION.md](cloud-journal/VERIFICATION.md).

## Render

Для структуры этого репозитория используется **render.yaml в корне репозитория**. В нём пути Dockerfile и контекста сборки указывают на `cloud-journal`. Конфигурации внутри `cloud-journal` сохранены для случая, когда сам проект размещён в корне отдельного репозитория.

Для ручной формы Render:

| Параметр | Значение |
|---|---|
| Name | `crane-journal-web` |
| Language | Docker |
| Branch | `main` |
| Region | Frankfurt |
| Root Directory | оставить пустым |
| Dockerfile Path | `cloud-journal/Dockerfile` |
| Docker Build Context Directory | `cloud-journal` |
| Health Check Path | `/healthz` |
| Auto-Deploy | Off |

Базу PostgreSQL и переменные окружения нужно настроить до запуска; значения берутся из корневого `render.yaml`. Этот файл описывает бесплатную демонстрацию: веб-сервис засыпает, бесплатная БД истекает через 30 дней. Для постоянного журнала нужны отдельно выбранные ресурсы и резервное копирование. Платные ресурсы данным пакетом не создаются.

Настройки MAX, пароли, существующий журнал и вложения не входят в репозиторий. Перенос данных: [инструкция](cloud-journal/docs/ПЕРЕНОС.md). Существующая Windows-программа пока не синхронизируется с облаком; после переноса используйте один веб-адрес на всех устройствах.
